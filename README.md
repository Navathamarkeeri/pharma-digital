# Digital Bridge

A simple landing page for a pharma-to-doctor platform built with React (CDN) and Tailwind CSS (CDN).

## Run locally

- Double-click `index.html`, or
- Serve with Python:
```bash
python -m http.server 8000
# open http://localhost:8000
```

## Share on same Wi‑Fi

Share: `http://<your-lan-ip>:8000`

## Share on the Internet

- Netlify Drop (drag `index.html`)
- GitHub Pages (enable Pages in repo Settings)
- Vercel (import repo)
